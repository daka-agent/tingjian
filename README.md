# 听见

一个二年级孩子，有话没说完。儿童公益叙事游戏，六幕、双视角、27 个镜头，完整体验约 15—20 分钟。

**在线玩：** https://daka-agent.github.io/tingjian/

本作不要求儿童当众发言，也不把"说出来"当作唯一正确的结果。三条表达路径——自己说、写下来、暂时只说给愿意听的人——都通向同一个结尾，不比较优劣。

## 怎么玩

直接用浏览器打开上方链接即可，手机竖屏体验最佳。无需安装、无需账号、离线也能玩。

| 操作 | 鼠标 / 触屏 | 键盘 |
|---|---|---|
| 继续台词 | 点击"继续"或对话区 | 空格 / 回车 |
| 选择回应 | 点击选项；多选时再点"就这些" | 数字键 1—4，Enter 确认 |
| 观察画面 | 点击发亮的微光 | Tab 聚焦后回车 |
| 打开目录 | 右上角"目录" | Esc |
| 静音 | 右上角"声音" | M |
| 给陪伴者的一页 | 标题页、目录、结尾 | 点击或 Tab |

结尾会生成本机的"约定卡"，可保存图片或复制文字，不上传。

## 说明

- 本仓库**只存放构建产物**（单个 `index.html`，CSS、脚本与六张场景图已内联），**不含源码、剧本与设计文档**。源码为私有仓库，由 Action 构建后推送至此，请勿直接向本仓库提交。
- 成品是浏览器游戏，内联的脚本与台词为明文，任何人查看网页源代码都能读到全部台词与分支条件（六张场景图为 Base64，不可读）。作者不打算加密剧本：这个故事本来就希望被读到、被讲给别人听。**需要保护的是源码仓库，不是故事本身。**
- 无账号、无排行榜、无留言墙、无第三方统计。进度与设置只写入浏览器 `localStorage`，可在目录里清除。
- 不要求填写姓名、学校、班级、住址或联系方式；约定卡只在本机生成。
- 场景图为 AI 绘制的概念稿，书本、黑板与布告栏上可能残留不可读的伪文字，不影响叙事理解。
- 环境声、铃声与翻页声由 Web Audio 实时合成，不是录音素材。
- 这个游戏不能替代专业帮助。如果孩子说出了让你担心的事，先听完，必要时联系学校心理老师或当地正规的儿童支持服务。
